# AI-Assisted Code Reviewer

AI-Assisted Code Reviewer is a Python-based web application designed to analyze source code, 
identify potential inefficiencies, detect common security vulnerabilities, 
and suggest code optimizations. Built using **Python, FastAPI, and Static Code Analysis**, 
the application examines code structure using Abstract Syntax Trees (AST) and heuristic-based analysis to estimate time and space complexity.
It highlights inefficient loops, potential security risks such as hardcoded credentials and unsafe function usage, and provides recommendations to improve code quality, readability, performance, and security.
The project aims to help developers understand their code better, write more efficient programs, and follow secure coding practices through a simple, interactive web interface.
